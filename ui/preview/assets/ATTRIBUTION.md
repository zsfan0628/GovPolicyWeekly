# Offline Map Assets

`world-outline.svg` and `china-region.svg` are schematic derivatives of Natural
Earth 1:110m Admin 0 countries, public-domain data. Generated with
`scripts/build_map_assets.py`; no online tiles or geocoding services are used.

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
- Terms: https://www.naturalearthdata.com/about/terms-of-use/
- Location markers represent cities/regions, not verified office addresses.
- This preview is not a standard administrative-boundary map; map boundary review
  is required before publishing it as an official geographic reference.
